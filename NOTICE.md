# Notice

This project started as an attempt to modify the GPL-3.0 licensed
`iamtheyammer/fetch-toyota-service-manuals` project. As the scope grew, most of the
application was rewritten into the current Electron desktop version, but the project
still grew out of that original work and retains/reimplements some of its manual TOC,
EWD, and local accessor ideas.

Some additional ideas were also informed by the GPL-3.0
`maburlik/fetch-toyota-service-manuals` fork, including broader TIS catalog discovery,
